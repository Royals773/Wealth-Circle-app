# Security Policy

Version: 1.0
Status: Final Policies
Effective date: 10 August 2026

Internal/operational policy — not published as a public page. Available on request per the Privacy Policy.

## 1. Purpose

This policy describes the security principles and controls used to protect WealthCircle and user data.

## 2. Security objectives

We aim to protect:

- confidentiality
- integrity
- availability
- accountability

## 3. Core controls

We should implement and maintain appropriate security controls, including:

- role-based access control
- least-privilege access
- strong authentication
- secure password handling
- encryption in transit
- encryption at rest where feasible
- audit logging
- secure backup and recovery
- vulnerability management
- monitoring and alerting
- secure vendor management

## 4. Access control

Access to production systems and personal data should be limited to authorised personnel only.

Access rights should be reviewed regularly and removed promptly when no longer needed.

## 5. Vendor security

Before engaging service providers that process or store data, we should assess their security posture and ensure appropriate contractual protections are in place.

## 6. Device and endpoint security

Company devices used to access sensitive data should be protected with passwords, updates, and other appropriate endpoint controls.

## 7. Change management

Material changes to systems, workflows, or data processing should be assessed for security impact before release.

## 8. Review

This policy should be reviewed periodically and after any significant security incident or major product change.
